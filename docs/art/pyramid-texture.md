# Desert pyramid texture

`public/maps/desert/pyramid.png` was generated with the built-in ImageGen tool, using the user's supplied beveled block image as a loose depth/material reference. The generated square image was resized to 512×512 for the shipped texture. Its base fills the image, so the same square can scale uniformly and rotate with the collision footprint. Both visual styles share the asset.

Final generation prompt:

> Use case: stylized-concept. Asset type: production top-down game obstacle texture for Fuse Riders desert arena. Generate one square sandstone pyramid, viewed exactly orthographically from overhead, with a perfectly 1:1 square outer footprint, sides aligned with image axes. Fill the entire square image edge to edge with the square base (no margins/background outside object); its four outer corners must coincide exactly with the four image corners. Four broad sloping triangular faces rise to a small square cap at the exact center. Strong baked 3D depth, upper-left face brightly sunlit golden sandstone, right and lower faces rich dark umber, crisp raised beveled ridges with thin warm highlights, subtle carved stone block seams and fine weathering, clean readable forms at 64-124 pixels. Loosely inspired by the supplied reference's substantial beveled block, dramatic face shading and tactile raised details, but make an ancient desert stone pyramid, not machinery. Warm sand/gold palette suited to dark neon arcade arena. Polished stylized 3D game asset, restrained texture detail, no perspective foreshortening, no tilt, no rotation, no text, no border, no mechanical fans, no objects outside footprint, no ground, no cast shadow beyond footprint. Output square 1024x1024.

Playtest: run `npm run dev`, choose **PLAY SOLO**, set **ROOM SETTINGS → Arena map** to **Desert**, save and start a match. Pyramids vary in size but remain square; some are aligned and others are tilted. Crashes, shell bounces, gun hits and bomb destruction follow the visible edges. The `map-styles-smoke.ts` browser script writes map contact sheets, a desert board preview and an isolated rotated pyramid to `artifacts/`, with browser and renderer names in each filename.
