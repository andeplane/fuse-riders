# Neural Defence

Neural Defence is a real-time territory RTS prototype: grow a connected network from a brain, mine **Biomass** and **Insight**, research, and direct a fixed pool of attack particles. Phase 0 is implemented locally for draft [PR #409](https://github.com/andeplane/fuse-riders/pull/409), including the headless core, Fuse Riders' shared neon/pixel UI and individual generated world sprites. Final verification and the user's visual/play acceptance remain open; no competitive balance or production claim follows from the current tests.

The first playable modes are a one-player sandbox without AI and a scripted combat lab with one opposing network and **one test tower**. The menu has **New game** and **Settings**; Settings currently offers reduced motion. Audio is not implemented. Each player has one builder for queued construction and 128 separate reusable attack particles. Growth, Excitation and Conduction research are independent. The engine supports 1–4 owners headlessly; online multiplayer UI is later work.

For outlined hexes and optional instant-job settings, open `/neural-defence/?mute&debug`; both instant options start unchecked, and costs plus travel remain in force. Dev servers choose a free port.
