# Fuse Volley art

Generated by `scripts/fuse-volley-art.ts` (edit the tables there, then rerun it; this file is rewritten on every run). The script calls the OpenAI image API with `OPENAI_API_KEY` from the environment, caches the raw images in `node_modules/.cache/fuse-volley-art/`, and fits them in a headless Chromium canvas to the exact sizes below in `public/games/fuse-volley/art/v1/`, with `manifest.json` beside them. The renderer draws a procedural fallback for any file that is missing.

Look: recognisably Blobby Volley (faceless jelly blobs, a beach court with a net, a volleyball, the sun and sky) in the Fuse neon style. The art is original; no Blobby Volley art is used. The code draws the blobs' eyes and the net, so neither is in the sprites or the court.

## Rerunning

```sh
pnpm exec tsx scripts/fuse-volley-art.ts                                  # every asset
pnpm exec tsx scripts/fuse-volley-art.ts --only blob-cyan --n 3            # three candidates, written to the cache for review
pnpm exec tsx scripts/fuse-volley-art.ts --only blob-cyan --pick blob-cyan=2  # fit the chosen candidate into place
pnpm exec tsx scripts/fuse-volley-art.ts --manifest                        # manifest and this file only
```

Regenerate the hero after the blobs, ball or court change: it uses them as reference images.
