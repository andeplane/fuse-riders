# Neon burrow production asset prompts

Built-in imagegen, using the accepted Neon burrow V2 screenshot as a style reference. Assets are material/backdrop sources, never collision geometry. Visual QA and runtime integration remain required.

## neon-rock

Create a production game MATERIAL TEXTURE for Fuse Birds Neon burrow. Square 1024x1024 seamless tile covering the entire canvas edge to edge with dark navy violet faceted rock. Style: rich hand-painted 2D game rock cross-section, near-black matte blue stone, layered violet strata, varied medium facets and cracks. Restrained contrast, sparse subtle cool highlights, no bright luminous outer edges because the game generates those dynamically. Front orthographic surface, no perspective. This will be clipped to arbitrary destructible hills/caves, so NO outline, no individual floating boulder silhouette, no scene, no sky, no water, no grass, no birds, no UI, no text, no border, no grid. Dense material throughout. Opposite edges should tile cleanly. Matching the dark rock interiors in the attached V2 art reference; reference only for material style, do not copy its scene.

## neon-sky

Generate a production 16:9 panoramic 2D background layer for Fuse Birds, matching the attached V2 Neon burrow game screenshot's distant scenery ONLY. Dark navy night sky taking upper 65%, subtle blue-violet distant archipelago silhouettes and ocean horizon in lower 35%, a muted violet moon upper right, sparse wispy clouds, atmospheric depth, restrained contrast so tiny bright game characters will be readable in front. No foreground terrain, no large foreground rocks, no slingshot, no birds, no crates, no HUD, no text, no frame, NO GRID. Polished illustrated game backdrop, gentle depth not photorealistic. No bright horizon stripe. The game will render its own destructible foreground and water.
