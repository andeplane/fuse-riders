# Catch up after a lagging snapshot

A room can fall behind on every device. A valid checkpoint slightly ahead of a receiver can still be far behind the receiver's log clock. Previously that checkpoint cleared the local catch-up grace. The next loop fetched again and skipped simulation, so similarly lagging peers could keep exchanging snapshots while an already delivered input waited for its stamped tick.

After an existing world installs a validated checkpoint, the runtime retains the existing bounded catch-up grace when the checkpoint is no newer, or when its estimated backlog still exceeds the same simulation-step threshold used to request a backlog checkpoint. During that grace the normal step/time budgets and stall bound govern forward progress. Manual repair, invalid-checkpoint retry, stream continuity, authority checks and atomic checkpoint validation are unchanged. No game rules, wire schema or simulation step ratios change.

The grace can delay another automatic backlog fetch for its existing finite duration. This trades repeated transfers of marginally newer checkpoints for local progress; a healthy checkpoint near the clock releases the grace normally. The typed `lagging-snapshot.test.ts` regression uses the real counter runtime, injected mesh clock and ordinary transport: it validates and installs a newer-but-lagging checkpoint, checks bounded progress, applies an ordinary input and compares peer hashes. Its catch-up assertion fails on the original runtime and passes with the catch-up policy. The counter fixture also round-trips the shared `away` seat field so those healthy checkpoints retain their hash during validation.

A temporary stream stall does not clear that grace: the actual log-clock backlog must fall below the existing threshold. The reachable tick still governs whether a backlog fetch is useful, preserving the rule that a blocked stream is repaired instead of fetching frozen snapshots. Repeated availability announcements from an existing world holder also preserve the grace; a hidden holder returning or a peer recently reporting no world can release it when that source becomes available. Regressions exercise dropped then restored fast packets and repeated ordinary hello messages, checking forward simulation progress and converged input results.
